## `/status`

`/status` 用卡片展示当前状态和操作入口，按会话概览、模型配置、上下文用量和任务进展分组。
完整的 Codex 会话 ID（Thread ID）、Netizen 会话编号和连接信息放在可展开的
「会话详情与订阅」中：前者供跨会话工具引用，后者供 `/resume` 等管理操作使用。再次发送
`/status` 或点击“查看状态”会发送一张新的状态卡。

普通会话（含持久分支）提供“查看状态”“停止”“会话配置”“会话列表”“归档”，分别等同于
`/status`、`/stop`、`/config`、`/sessions`、`/archive`；Side 提供“查看状态”“停止”“结束临时会话”，
分别等同于 `/status`、`/stop`、`/side close`。是否开启过程卡不影响这些入口。
点击后的反馈与发送对应命令一致：配置仍打开独立的配置卡，当前不能配置时会说明原因；停止
针对点击时该会话正在执行的任务，Goal 同样先暂停。归档先打开确认卡，确认后保留历史并清空
当前会话，之后可从 `/sessions archived` 恢复；尚未开始的会话还没有 Codex 历史，会提示无法
归档。按钮不会绕过原命令的限制或确认。

每张状态卡只对应生成时的会话及聊天／话题。切换当前会话后，旧卡片不能操作新会话，也不会
自动切回原会话，请重新发送 `/status`。同一会话开始新一轮后，旧卡片仍可操作，停止针对当前
正在执行的任务。Side 结束、过期或不可用后，旧卡片不能恢复它，也不能操作原会话。
操作后，原卡片保留查询时的内容，不会自动变成最新状态；如果提示操作入口更新失败，请重新
发送 `/status` 后再操作，刚才的命令不会自动重试。

会话预览会隐藏附加的消息来源信息。状态卡通常包含：

- 当前会话的短 ID、名称和首条消息预览；
- Project、完整的 Codex 会话 ID 和运行状态；Project 位于 Git 仓库中时还显示当前分支信息，
  Side 的状态也显示同样的信息；
- 当前这一轮的任务步骤（checklist）和已接收的补充消息次数；
- 最近一次完成的任务所用的上下文窗口；窗口大小可知时，同时显示上限和已用百分比；
- Model、Effort、Speed，以及它们来自 Netizen 会话配置还是继承 Codex；群聊会话还显示
  @ 时读取的消息范围；
- 本服务当前与该会话的连接状态，以及自动断开的倒计时。

任务步骤可能尚未生成，或当前版本暂不支持；上下文用量也可能要等这一轮完成后才更新。Git
信息来自一次快速的只读检查，不是 Git 目录或检查失败时会省略，不影响其他内容。`/status`
不展示内部推理、完整的工具日志或预计完成时间。

当前固定的 Codex 版本默认关闭生成任务步骤的 `update_plan` 工具。需要任务步骤时，可在
Codex 配置中把 `tools.update_plan.enabled` 设为 `true`；Netizen 沿用这项配置，不会自动开启。
开启后，任务步骤仍要等 Codex 实际生成，其他过程信息的展示不受这项开关影响。

任务步骤用 `✓ completed`、`→ inProgress`、`○ pending` 表示。补充消息成功加入后，旧的步骤会
标注为可能尚未反映最近的调整；收到下一次完整的步骤更新后整体替换，并清除这个标注。
后续新一轮任务运行时，上下文用量保留上一轮的数值并标为“上一轮完成时”，本轮完成后再更新；
用量未知时会明确说明，不会当成零。

连接状态只反映本服务此刻的情况，不代表会话在 Codex 中的生命周期。断开最后一个连接后，
Codex 还要再等 30 分钟没有连接和活动才会卸载这个会话，所以 `/release` 不代表会话已立即释放。

## `/usage`

发送 `/usage` 可查看服务所用 Codex 账号当前的剩余额度、各限制周期和重置时间。
卡片中的进度条和百分比都表示剩余量，重置日期、时间与时区按你的飞书客户端设备显示。
Codex 返回模型专属额度、Credits 或月度额度时也会简短展示。
命令不接受参数，不需要先创建会话，在有效的 Side 话题中也可以查询；群聊中仍需 @机器人。

这是所有使用同一 Codex 账号的任务共享的额度，不是当前飞书用户或会话的独立额度，也不是
`/status` 中的上下文窗口用量。卡片只展示本次查询时的数值，不是 token 账单或费用统计。
没有提供重置时间时会明确标注；显示的重置时间也不能当作任务一定可以恢复的保证。

未登录、当前账号不支持、查询超时或 Codex 暂时取不到数据时，会提示额度暂不可用，不会把
未知当成零。可请部署者检查服务所用 Codex 的登录状态，或稍后重新发送 `/usage`。
如果当前版本不支持额度查询，命令会明确拒绝，也不会出现在 `/help` 中。

## `/compact`

- 发送 `/compact` 压缩当前普通会话的上下文，不接受额外参数；会话需要已有任务历史并处于空闲。
- 如果开始前读取会话历史超时或多次失败，会明确回复压缩未开始，会话恢复可用。
- 开始后状态显示为 `compacting`，完成前不能提交新任务、修改配置或再次压缩。完成后可以在
  同一会话继续提问。
- `/stop` 不会中断压缩。压缩结果无法确认时，按回复中的提示处理，不要把开始回执当作完成。

## `/stop`

- `/stop` 中断当前聊天位置正在运行的任务；当前会话没有运行任务时，不会停止其他会话。
- 如果正在运行的是 Goal，会先暂停 Goal（暂停会被保存），再中断它正在执行的这一轮。
- 随后 Netizen 会请求 Codex 清理它登记过的后台终端。
- 重要限制：当前接口不保证前台工具进程退出。飞书显示“已中断”表示这一轮任务已经停止，
  不代表所有前台子进程都已退出。
