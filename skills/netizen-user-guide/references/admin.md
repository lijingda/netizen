发送 `/admin` 可找回当前实例实际绑定的管理 URL 和根目录，无需先登记 Project 或创建
会话，也不会调用模型。有效的 Side 话题同样支持；关闭或过期的 Side 仍返回原有结束提示。

## 访问与登录

Admin 默认监听 `0.0.0.0`；首次未指定端口时从 `8787` 开始寻找可用端口，绑定后保存在
本实例配置中，之后不自动换号。多实例的管理端口彼此独立；不要仅凭默认端口猜测入口。
默认监听时，`/admin` 从启动时发现的网卡 IP 中筛选并最多展示 4 个访问地址；网络地址
变化后需重启实例刷新。
多网卡或服务器名称不明确时，部署者可在本实例 `config.yaml` 中设置 `adminWeb.accessHost`。
仅提供 loopback 地址时需在服务器本机访问或自行建立隧道。`/admin` 不返回登录凭据、
session token 或免登录链接，也不改变管理权限。打开管理页后点击飞书登录，在官方页面
完成确认，再回原页继续。不要在聊天中发送 App Secret 或用户 token。Admin 使用受信内网
HTTP，名单中的管理员权限相同，不提供 TLS、角色分级或 Project ACL；不应直接暴露到
不受信网络。普通使用者继续在所在聊天或话题中使用 `/projects`、`/defaults` 和会话命令。

## 管理员与登录状态

首位管理员由部署者在本机 setup 中授权确认，或通过 `--admin-open-id` 指定当前应用下的
用户 Open ID。已有管理员可在“访问控制 → 管理员”中使用飞书选人组件添加
成员，或确认删除；可以删除自己，但不能删除最后一人。名单展示姓名、头像的本地快照，
手填 ID 尚无资料时显示 ID；当前登录者标记“你”，只有一位管理员时显示不能删除的原因。展示信息陈旧不会改变权限。删除会立即撤销该用户所有管理
登录和未使用的操作授权，已经受理的任务继续运行。重新添加不会恢复旧登录。

本地登录状态不会因闲置或使用时长自动过期。退出登录、服务重启或浏览器清除会话
Cookie 后需重新登录；服务器保存飞书凭证不等于浏览器自动恢复登录。实际调用飞书时
会按需续期，续期失败需要重新登录。普通退出只结束当前浏览器登录，不清除共享用户
凭证。登录会话数量达到上限时，新登录会替换最早会话，优先替换已满来源的会话。

登录授权有有效期，取消、过期或失败时按页面提示重新开始；保留原页直到授权结果返回。
已有飞书登录态可能减少扫码步骤，但不保证跳过授权确认。新登录统一申请选人和按需
续期所需的 `component:selector`、`offline_access`；不在进入管理员页面时另行补授权。
连续失败触发限速时按提示等待后重试。管理操作凭据仍有十分钟有效期，操作页面过期时
需要刷新。旧共享密钥登录已移除，飞书登录失败不会回退到旧方式。

## 群聊准入

“访问控制 → 群聊准入”显示当前允许执行的群聊。默认是“全部群聊”：能使用机器人的群成员
共享服务账号的工具和文件权限。需要限制时，管理员可改为“仅已启用的群聊”。单聊和单聊
话题不受影响；群聊按聊天 ID 名单启用，一个群的设置覆盖其主线和全部话题，包括话题群。

实例管理员可在需要启用的群里 @机器人并发送 `/enable`，不带参数；在话题中发送也会启用
整个群。未启用的群也接受这条命令，其他成员无法启用。单聊无需启用。
“全部群聊”模式下也可先用 `/enable` 把群加入名单，之后切换为“仅已启用的群聊”时生效。

也可使用群聊选择器添加群，核对群名和聊天 ID，或直接编辑 ID 名单。重复 ID 只算一个，
最多 1000 个，超出数量时页面会提示修改。名称暂缺时显示聊天 ID，可刷新补全。
切换限制模式不会自动添加群，保存前请核对名单；漏掉的群可随时由实例管理员发送 `/enable`
启用。切回“全部群聊”仍保留名单；“放弃修改”或重新加载恢复已保存名单。移除群和切换
模式都在 Admin 中进行。

保存后，新消息、命令、卡片按钮和定时投递都遵守新规则。未启用的群中，除 `/enable` 外，
@ 机器人会收到未启用说明。点击卡片按钮也不会执行，原卡片保持不变，机器人会尽力回复说明；
同一人重复点击同一按钮不会再收到回复。群重新启用后，请重发命令取得新卡片，旧卡片上点过的按钮可能暂时无效。
已有会话和定时计划仍保留，正在执行的任务继续运行并回复；但群内无法回答任务的问题，
也不能通过卡片停止或归档。需要处理时在 Admin 管理，或重新启用该群。
定时任务或跨会话协作暂时无法确认聊天信息时，会提示验证失败，而不是“群未启用”。
规则不会改变 Codex 自身的工具、文件权限或审批设置。

## 页面导航与表单

左侧导航按用途分组，每页都有独立地址：

| 分组 | 页面与地址 |
| --- | --- |
| 会话 | 普通会话 `/sessions/ordinary`、临时会话 `/sessions/temporary`、定时任务 `/schedules` |
| 资源 | Project `/projects`、worktree `/worktrees`、文件附件 `/attachments` |
| 默认配置 | 会话默认配置 `/defaults`、全局过程卡 `/progress-card`、提问通知 `/question-notifications` |
| 访问控制 | 管理员 `/admins`、群聊准入 `/group-access`、跨会话工具权限 `/session-tools` |
| 运维 | 服务与诊断 `/maintenance` |

旧 `/system` 链接会进入 `/admins`；首页 `/` 仍进入 Project。窄屏顶栏显示当前页名，
点击“菜单”展开导航；选中页面、按 Escape 或点击关闭／遮罩可收起。
已应用的筛选、排序和每页数量保存在地址的 `?`
查询参数中，未点击“筛选”的修改不会写入。例如
`/sessions/ordinary?project=netizen&sortBy=createdAt&sortDirection=asc`。
可以收藏或复制地址；浏览器前进／后退和整页刷新会恢复对应查询条件，重新读取第一页，
不恢复旧列表快照、翻页游标或旧操作授权；整页刷新不会保存表单草稿。未登录时先完成登录，再回到原管理地址；
只允许返回本实例的管理页面。旧的 `/?binding_id=...` 会话链接仍可使用。

Project 添加、worktree 创建与配置、会话配置、默认会话配置和定时任务的抽屉，有未保存修改时关闭、取消、按 Esc 或
离开编辑界面会询问是否放弃；选择取消可继续填写。改回原值、仅打开查看或保存成功后
不提醒。有修改时刷新或离开整个页面会请求浏览器原生提醒，但不会自动保存草稿。
等待导航确认期间，尚未返回的列表查询不会改变地址或历史位置；确认后进入原目标页，
取消后保留原地址、列表和草稿，仍可继续使用浏览器前进／后退。

群聊准入、跨会话工具权限、全局过程卡和提问通知各自保留尚未保存的输入。
修改后对应导航项显示“未保存”；切页或浏览器前进／后退不自动保存、重置或覆盖修改。
返回没有修改的配置页会重新读取；有修改时只有显式“刷新”才在确认放弃后重读。
隐藏的修改仍在退出登录、刷新或离开整个页面时提醒。选人组件切页时收起，已选人员保留，
返回后可直接确认添加或重新加载组件更换人员。附件目录只在打开浏览器或显式刷新时读取。

手机窄屏将列表显示为卡片，标题与状态在顶部、字段带标签、操作在底部；
普通／临时会话的时间排序仍可使用，抽屉和文件浏览器可直接在当前页面操作。

页面主操作使用实心主色按钮，行内操作使用紧凑描边按钮；删除、结束临时会话等不可逆操作
使用红色提示，停止、归档、暂停和释放订阅使用普通按钮。确认在页面内弹窗中进行，默认选中“取消”；按 Escape、点击关闭或遮罩也会取消，并回到触发位置。确认后请求返回前按钮保持禁用。

会话列表的运行态、订阅状态及会话目录状态使用中文，未知状态保留原值供核对。
会话、默认配置和定时任务的配置摘要按消息上下文、模型、推理强度和速度展示；
列表始终显示模型、推理强度和速度的精确 ID；编辑器内可显示对应名称，打开编辑器不会改变列表摘要。

普通会话每行直接显示至多三个常用操作，其余在“更多”浮动菜单中；定时任务和群名规则也将次要操作收进菜单。
菜单用方向键移动，Enter／空格执行，Escape 关闭并返回“更多”，点击外部、滚动或调整窗口大小会收起。
危险操作在菜单底部，以红色和分隔线提示。

列表头部显示“更新于 HH:MM:SS”。读取失败时，错误条和“重试”在对应列表附近，仍保留上次成功的内容、分页及时间；
成功读取为空才显示空态，可按提示添加内容或重置筛选。操作结果显示在页面顶部，滚动时仍可见；
成功提示数秒后消失，错误、结果未知或需要刷新核对的提示保留到关闭或下一次操作。
刷新列表不会清掉操作回执，登录过期只显示重新登录横幅。页面的详细使用边界可展开“说明”查看，
删除等确认弹窗仍完整说明后果。

## 定时任务内选择原会话

创建计划时选择“在原会话继续”，可直接在抽屉内搜索并选择会话，也可按 Project、群聊
筛选。默认显示未归档会话且不限更新时间；可切换“已归档”或“未开始”，未开始的会话
不支持名称搜索。结果列出名称、位置、Project、当前／归档状态和最近更新，支持上一页、
下一页。搜索规则与普通会话列表相同，输入后按 Enter 或点击“筛选”应用。

选中后显示目标摘要；目标不是可执行的当前会话时，会提示计划将自动暂停，不会自动
切换或恢复会话。创建时可点“更换”重新选择，编辑已有计划时目标不能更换。
名称、指令和时间始终保留在当前抽屉；搜索和翻页本身不算未保存修改，选中或更换目标
会参与放弃提醒。刷新整个页面仍会丢失未保存内容。
普通会话行的“更多 → 创建定时任务”继续直接预填该会话。

## 全局过程卡配置

在“默认配置 → 全局过程卡”打开“全局过程卡配置”，可修改进展、操作与任务清单的显隐，
进展/操作的条数、摘要长度和组织方式，点击“保存配置”生效；“放弃修改”恢复本次加载
或上次保存的值。取值范围见[配置过程卡内容](feedback-and-files.md#配置过程卡内容)。

全局配置仅供本实例未单独配置过程卡的会话使用，不覆盖会话或聊天默认配置中已有的
过程卡设置。已有设置即使与原默认值相同，也继续按显式配置保留。保存后，普通会话
下一次任务、Goal 下一次新执行和之后创建的 Side 才使用新值；正在执行的卡片和已有
Side 保持原设置。过程卡总开关仍在各会话中独立控制。

会话及默认配置表单未单独配置过程卡时，会显示当前全局值供编辑；修改过程卡细项并
保存后才成为该会话或默认规则的显式设置。只改模型、过程卡总开关或其他选项不会固定
这份全局值。已有单独配置时，可点击“恢复跟随全局”，表单会显示当前全局值；保存后
从后续任务开始跟随，取消或放弃修改仍保留原设置。未单独配置时不显示该按钮。
普通会话和会话默认配置列表在过程卡开启时标注“过程卡：跟随全局”或“过程卡：单独配置”。

## 提问通知

在“默认配置 → 提问通知”设置“提问时 @ 发起人”，默认关闭，点击“保存配置”生效；
“放弃修改”恢复本次加载或上次保存的值。开启后，每张新问题卡都会 @ 本轮任务的明确
发起人，多题分别提醒；没有明确的人类发起人时不 @，不改为提醒最后追加消息的人或
定时计划创建者。

此设置属于本实例全局，与会话的过程卡、结束时 @ 提醒独立。新卡发送时采用有效设置，
不回补旧卡；原卡更新、回答反馈及重复观测不追加提醒，也不另发一条提醒消息。
提醒不表示任务一定暂停。真实飞书客户端是否产生通知仍需按客户端和群设置确认，
不能仅凭卡片发送成功保证系统通知已弹出。

## 文件附件管理

在“资源 → 文件附件”点击“浏览附件”，查看本实例从飞书保存的输入原件；不包含
Project 文件、会话输出文件或任意服务器目录。进入附件页不读取文件树，打开浏览器
后才列出批次，按保存时间和短 ID 辨认；逐层展开时读取对应目录，不扫描全部附件或
统计全量数量、占用。时间按浏览器本地时区显示，文件详情的“保存于”不是原始上传时间。

文件名筛选在电脑上覆盖已加载条目，在手机上仅覆盖当前目录。选择文件即可查看名称、大小和保存时间；支持的文本、
Markdown 和图片使用与[Project 文件](#查看-project-文件)相同的预览控件与限制。
PDF、Office 或超限文件无法预览时，仍可查看元数据和删除；没有上传、下载、编辑、
批量删除或递归删除目录入口。

下载完成并完整保存的附件即可管理，不等待任务受理或执行结束。“删除附件”每次只针对
选中的一个原件，需确认：删除可能使正在执行或后续任务无法读取它，需要时请重新发送。
删除不停止任务，也不扫描所有会话判断附件是否仍被引用；最后一个原件删除后，准确归属
且已空的批次目录会尽力清理；空目录清理失败不影响已确认的文件删除或后续附件输入。

删除成功后只更新受影响目录；响应丢失或结果未确认时，按提示刷新核对，不重复提交。
若当前文件或批次已由另一管理员删除，刷新会清除旧选择，批次不存在时返回重新读取的
根目录。关闭抽屉或登录失效会清空显示；Project 文件入口始终保持只读。

## 普通与临时会话

Admin Web 只管理已有会话，不提供新建会话入口。请在目标飞书聊天或话题中通过 `/new`
或可用的聊天默认配置创建会话；定时任务仍按保存的计划执行。
它可以管理任意聊天或话题中的会话（包括非当前会话）：设为当前、修改完整会话配置、
重命名、归档、恢复或恢复并设为当前、删除尚未开始的会话（按钮“删除未开始的会话”）、停止和
释放连接（Stop、Release）；在当前版本支持删除时，也可以删除未归档或已归档会话的 Codex
历史。两类删除都需要二次确认；删除已有 Codex 历史的会话时，确认框会显示会话、Scope
和短 ID，并说明 Codex 会话、它派生的子任务（spawned descendants）、Codex App/CLI 历史与
Netizen 中的记录都会永久消失。它不能发送即时任务、查看完整历史、启动或推进 Goal、压缩
上下文、清理已结束 Side 的记录，也不能对任意选中的多个会话批量执行 Codex 操作。Admin
可以查看 @ 时读取的消息范围，但没有对应的飞书消息作为起点时，不能新启用“自动带上期间
的群聊讨论”，也不能把使用这种模式的后台会话直接设为当前。页面操作结果未知时请刷新
核对，不要重复提交；服务重启或凭据轮换会让原登录失效。

导航的“会话”分组直接进入“普通会话”或“临时会话”，切换时分别保留
各自的筛选草稿、已应用查询、排序、分页与刷新时间。
筛选或翻页成功后，列表和分页一起更新；查询失败时继续显示上一次成功结果，不丢失

普通会话的“配置”打开完整会话设置表单，可修改模型、推理强度、速度、表情反馈、

普通会话的“会话状态”一次选择未归档、已归档或未开始，默认未归档。
“Project”“Scope”（单聊、群聊或话题）和“当前指针”（是否为当前会话）支持多选，同一项取“或”，不同项取“且”；Project 可搜索并包含停用项目。

“重置”恢复以上默认条件、清空关键词、最近更新由近及远和每页 20 条。目录读取失败会提示重试，

未设置群筛选时，机器人退出群后的已有会话仍保留在原列表中。
分页栏的“每页”可选 10、20、50 或 100 条，修改后按已应用条件查询第一页，不提交筛选草稿。
普通会话的“位置”合并聊天名、单聊／群聊／话题与消息／话题类型；“状态”合并目录状态、

预览最多显示两行；内容较长时点击预览或“展开”查看全文，再点一次或点“收起”恢复。

改名后可能延迟更新；服务重启或缓存淘汰也会触发重新查询。接口失败或无法解析的结果

排完后才分页，切换排序回到第一页，不提交尚未应用的筛选草稿。相同时间按 ID 固定顺序。
普通会话的创建时间与最近更新都使用 Codex 原生时间，按浏览器本地时区显示。
未开始的会话尚未在 Codex 创建，选择“未开始”后显示并按 Netizen“登记时间”排序，更新时间显示
“尚未开始”，原生创建／更新时间筛选不适用。缺失原生时间显示 `—`，不用登记时间替代。
列表按所选状态逐页查询，只展示本实例登记的匹配会话；筛选很稀疏时可能需要读取更多
候选。“下一页”表示仍可继续查询候选，因此下一页可能没有匹配结果。列表不是固定快照，
会话变化可能改变分页位置；需要重新核对时可回第一页刷新。
从来源会话或定时触发记录打开的精确 ID 链接不限时间，默认查未归档；没有找到时可切换

由原生列表发现；此限制不会删除会话。

100 条，默认 20。“重置”恢复临时会话自己的默认筛选，不改变普通会话的条件。
列表显示位置、来源会话、状态、Project、创建时间、最近更新和操作；状态同时显示会话与运行状态，原始 ID 在折叠详情中。
临时会话的最近更新来自其自身记录，接受输入、任务结束或生命周期变化时更新，不是来源
会话的更新时间，也不随逐字输出变化。

Side。正在关闭时仍显示结束中，已结束或失效且没有运行任务的记录显示 `—`。
可用按钮随会话情况变化：“停止”与 Side 中的 `/stop` 相同，只中断当前任务，临时会话
仍可继续；“结束临时会话”与 `/side close` 相同，结束后不能恢复。旧页面的停止操作

表格工具栏右侧可选择“紧凑”“本页按项目分组”或“本页按聊天分组”，分别只重排当前

展开”“全部折叠”，只影响当前页。组头的“本页 N 条”只统计本页会话。两类列表、两种
分组分别记忆本次页面内的折叠选择，刷新列表、翻页或切换页面后保留，整页刷新后重置。
切回紧凑布局显示本页全部行并恢复原顺序。切换布局和折叠不请求新目录、不更新最后

已确认归档且没有待核查运行活动的会话，运行态显示 `—`（已归档，不查询运行态），
这不表示历史 Goal 不存在。普通和临时会话列表均不再常驻自动刷新，页面显示最后成功

## 查看最近一轮回答

在普通持久会话的“更多 → 查看最近回答”中，查看该会话最近一轮的最终回答。按钮只在
当前具备读取条件的会话上显示，包含可读取的已归档会话；未开始的会话和 Side 不提供此入口。
读取不会恢复归档、继续执行、重新生成答案或补发飞书消息，分支按自身可见历史读取，
可能包含继承的内容。

这里只读取最新完整一轮并展示其最终回答；没有最终回答时展示该轮状态，不向前找旧答案。
执行中的进展、阶段性答案、推理、工具输出和输出文件不作为最近回答展示。Goal 的某一轮
回答不代表整个 Goal 已完成。读取失败、历史缺失与“本轮没有回答”分别提示。

抽屉展示本次读取时刻及原生有值的开始、完成时间，不用会话更新时间补造轮次时间。
这是一次读取快照，需要更新时点击“刷新”，不会后台轮询或循环等待答案。

正文默认以 Markdown 排版展示，支持标题、列表、表格和代码块，可切换“查看原文”。
读取时间及轮次信息在“本次读取详情”中展开查看。超出排版限制或预览暂不可用时显示
完整原文。已完成轮次中，正文引用且历史中保留了图片内容的原生生成 PNG 可以直接展示；
不额外列出未被正文引用的图片。图片缺失、过大或不支持时保留说明，不影响阅读文字。
本地文件链接不打开，其他来源的图片不加载，网页链接可在新窗口打开。

## Project 统计与删除

点击 Project 页的“添加 Project”打开抽屉，可选择登记已有目录或创建空目录。
登记时绝对路径必填；创建时可留空，按实例项目根目录和 Alias 创建，自定义路径仍须
位于项目根目录内。切换方式保留 Alias 和各自的路径输入，提交只使用当前方式。

Project 页展示本地项目与会话统计，不展示归档数或待确认数。每行“查看会话”进入普通
会话列表并应用该 Project，其他条件使用与首次进入、重置相同的默认值；不会保留先前的
关键词、群、精确会话 ID 或页码。当前默认为未归档、最近三个月更新、最近更新由近及远、
第一页 20 条。项目条件可清除；查看该项目的归档会话时，将状态切换为“已归档”。
Project、定时计划及最近触发记录均提供“上一页／第 N 页／下一页”。分页不显示精确
总数，不支持任意跳页；翻页失败保留当前页，可重试。
Project 页每行的“删除…”打开删除确认弹窗。确认范围包含该项目的全部关联会话
（含归档会话）、仍需关闭的 Side、定时计划和仍在创建会话的定时执行，不受会话
筛选影响；原 Project 磁盘代码目录保留。弹窗内可勾选“同时删除 N 个关联受管 worktree”，
默认不勾选；没有关联 worktree 时不显示此选项。勾选后更新删除范围并列出涉及目录，
预览完成后才能确认删除；读取失败时须关闭弹窗后重新打开。取消或按 Escape 不提交删除。
浏览器前进、后退切换页面时也会关闭未确认的弹窗，返回后需重新打开并确认。
勾选后也必须通过 worktree 安全检查，不能强制丢弃成果。提交后关联计划即删除，部分删除失败或同名 Project
重新登记都不会恢复这些计划。
全部成功后项目才从列表移除。部分失败、结果未知或 Side 尚在创建时，项目保持停用并
展示剩余项；已成功删除的会话不会恢复。后续操作须刷新清单并重新确认，不会自动续删。

未勾选删除 worktree 时，保留的 worktree 仍在全局列表中，标示原 Project 已删除；不能再在
`/new` 中选择，也不会因同名 Project 重建而自动挂回。本版不提供重新关联入口，请先
自行处理内容，再在 Admin 删除或清理缺失登记。

## 查看 Project 文件

在 Project 每行点击“查看文件”，可浏览服务器上的当前目录。默认使用 Project 登记目录，
也可明确选择该 Project 的受管 worktree；当前工作目录显示在目录浏览页顶部。停用 Project
仍可查看，删除中、目录缺失或身份变化时按提示重新选择。这里展示当前磁盘内容，
不是某个会话或某次执行的文件快照。

电脑上的目录树可逐层展开或收起，同级目录和已展开的分支会保留，收起目录不关闭正在查看的文件。
文件名筛选只检索已经加载的目录条目；“收起所有目录”释放子目录列表，后续展开重新读取。
手机上每次展示一层目录，点击文件夹进入下一层，点击文件进入独立内容页；“返回目录”
恢复之前的列表位置与筛选，“上一级”返回父目录。手机筛选仅匹配当前目录；刷新在目录和
内容页均可使用。文件附件管理使用相同的手机交互。
“刷新”重新读取当前文件所在目录或选中的目录，面包屑可定位上级或根目录。代码和文本支持行号、
查找、跳行、自动折行与全文复制；Markdown 可切换源码和预览，项目内相对链接可点击
查看。PNG/JPEG/GIF/WebP 小图可直接预览。复制失败时可在源码中选择文本后手动复制。
首版不提供下载、编辑、上传或删除文件。

预览有大小限制：文本最多 1 MiB、10,000 行、单行 20,000 字符，Markdown 排版预览最多
256 KiB；图片最多 5 MiB，画布最多 16M 像素且单边不超过 8192。大文件、其他编码和
不支持的格式会明确提示；目录条目超过 2,000 时提示列表不完整。符号链接不跟随，
所选根内的 `.git` 目录项不展示。单次打开的目录树最多保留 10,000 条已加载条目，达到上限可先收起
所有目录再继续，手机上可返回根目录并刷新。HTML/SVG 作为源码，Markdown 内的远程图片不自动加载。
隐藏文件与未跟踪文件可能包含配置或敏感内容；查看范围使用现有实例管理员权限。

文件查看按需读取，不调用模型，不消耗模型 token。关闭抽屉或发现登录失效会清空显示，
但浏览器已经接收或用户已经复制的内容无法撤回。

### 查看相对 HEAD 的改动

当前目录位于 Git 仓库时，目录树上方会多一个“只看变更”开关，目录树也会给修改、新增和
未跟踪的文件加标记，被忽略的文件显示为灰色。改动指工作区相对当前提交（HEAD）的差异，
暂存和未暂存的修改一起计算。它反映此刻磁盘上的状态，包括你自己和其他会话的修改，不代表
某个会话或某次执行改了什么。不是 Git 仓库的目录没有这个开关，其余功能不变。

打开“只看变更”后，已经展开的每一层只显示有改动的文件和含改动的文件夹，展开状态与完整
目录相同，开关不会自动展开或收起目录。这一层被删除的文件、整个被删除的文件夹会补成带
“删除”标记的行。被忽略的文件不算改动，要看它们请关闭开关，在完整目录中查看。文件名筛选
可以和开关同时使用。

文件打开后可以在源码、预览（Markdown）和差异之间切换。开关打开时，修改或删除的文件默认
显示差异，否则默认显示源码。差异默认只显示改动和前后 3 行，折叠处有一行按钮，可以向下或向上
展开 20 行，或展开这一段全部；工具栏的“展开全部”会展开整个文件。电脑上可以在左右分栏和合并
显示之间切换，并记住你的选择，手机上固定合并显示。手机上源码、预览和差异的右侧会一直
显示滚动条，标示当前位置；预览和差异的滚动条可以直接拖动，源码请上下滑动内容。
新文件没有旧版本，直接显示内容。差异沿用上面的文本大小限制；二进制、过大、符号链接或只
改了权限的文件只提示改动类型。

改动信息在打开查看器或点“刷新”时读取一次，查看期间不会自动更新；Codex 仍在改文件时，
刷新即可看到最新状态。改动超过 10,000 条时会提示不完整，可改为只看当前目录的改动；此时
目录树上没有标记的文件不代表没有改动，打开文件后仍可查看它的差异。查看期间 HEAD 变化
（例如有了新提交）会提示刷新。使用 LFS、git-crypt 等 Git filter 的文件可能显示为已修改，
差异按磁盘上的原始内容比较。Git 不可用或读取超时时，开关旁显示原因并可重试，浏览文件
不受影响。子模块和嵌套仓库内的文件可以查看内容，但不显示改动。

## worktree 配置与管理

worktree 页管理本实例创建并登记的 worktree，不创建普通会话；要开始对话，请在飞书
`/new` 选择该 worktree。手动 Git、Agent shell、Codex App/CLI 或其他实例创建的目录不会
自动收编。进入页面、翻页或手动刷新时查询当前状态，不持续后台扫描；显示目录、分支/
detached HEAD、状态和关联会话数。目录缺失、身份改变和状态未取得分别展示，不会据此
自动删除登记或会话。

页头“新建 worktree”和“创建配置”分别打开抽屉；新建表单只读显示当前创建配置，
修改配置需从“创建配置”入口单独保存。列表刷新不清空正在填写的表单。创建或保存失败
时保留输入，结果未确认时可只读刷新核对，不自动重复提交。

配置包括后续新建根目录和“创建前 fetch”。根目录留空使用本实例的 `worktrees` 子目录；
改根不移动已有目录，也不修改 Codex App 全局设置。fetch 默认关闭，开启后 fetch 失败
会停止创建，不静默用旧结果继续。新建可选择 detached、未占用的本地分支或新分支；
默认起点为 Project 当前 HEAD；其他起点可填写分支、标签或提交，检出已有分支时填写
本地分支名。表单不查询分支候选列表，提交创建时检查 ref 和分支占用。不复制提交之外
的文件、不运行环境初始化。

每行可选择“同时删除关联会话”，默认不勾选，然后预览将被删除的具体范围并二次确认。
不勾选时保留会话历史与原 cwd；勾选时先按原生规则删除关联会话和结束相应 Side，
再安全删除目录。保留关联会话时，其活动或未知状态及仍存活 Side 会阻止删除；未纳入
级联的已知使用会话或创建来源仍在活动或状态不明时也需先处理。未保存文件、忽略/未跟踪文件、
未保留的 detached 提交或路径身份异常，都会要求先处理再重新预览；
勾选级联不等于允许丢弃成果。没有快照恢复或自动回收。

删除仅依据本实例已知关联，不能证明没有外部客户端正在使用。部分成功或结果未知时，
先刷新核查剩余资源，成功项不回滚，也不会自动续删。已缺失目录提供显式“清理缺失登记”；
只要目录重新出现或身份无法确认，就不会当成原资源直接移除。删除/归档单个会话不会
自动删除 worktree。

新话题定时计划可选择已有 worktree 或每次新建；配置与运行见
[worktree 使用方式](scheduled-tasks.md#worktree-使用方式)。删除被计划引用的 worktree 不会删除该新话题
计划，会显示不可用原因并停止接受该计划的执行。若选择同时删除关联会话，以被删会话为
固定目标的原会话计划仍随之删除。修改或删除计划不会自动回收已生成的 worktree。

## 服务与诊断

“服务与诊断”显示当前 Python 安装、当前实例诊断与最近重启结果，只提供本实例“重启服务”，不再从
管理页升级共享程序。程序升级由部署者在独立终端执行 `netizen update`，不能从将被
停止的 Netizen 服务里执行。

实例诊断与 `netizen doctor --root` 使用相同的只读服务检查，展示注册、加载、运行、
就绪和自启动状态，环境详情可展开查看。进入页面或点击“刷新维护状态”时检查，不自动
轮询诊断；检查失败显示“无法确认”，上次成功检查时间不冒充本次结果。此检查不包含
飞书权限、模型连通性或数据库完整性。旧升级的已结束结果不再显示为当前告警；历史
维护未完成或结果未知时仍提示核查，不自动清除记录。

重启使用此实例已经绑定的 Python 环境中的当前程序，重新加载账号持久 shell profile，
并执行启动数据检查与必要迁移；它不安装包、不切换 Python 环境，也不保证所有原生
配置作用于已有 Thread。提交前确认停机影响：不等待任务空闲，会中断普通任务、
暂停 Goal、结束临时 Side，之后不会自动续跑。重启失败不自动回滚用户配置或已迁移数据库。

关闭页面、断线或等待超时不取消操作；响应丢失先刷新对账，不要重复点击。重启后需要
重新登录查看同一操作的结果；页面连通不等于操作成功。“服务已恢复”只表示恢复证据
得到确认，不改判原失败操作。结果未知时按提示检查实例状态与日志，不手改维护记录
伪造成功。服务已经停止时管理页不可用，由部署者使用：

```bash
netizen status --root /absolute/path/to/.netizen
netizen logs --root /absolute/path/to/.netizen
netizen restart --root /absolute/path/to/.netizen
```

这些是宿主机 CLI 命令，不是飞书 slash 命令。`--root` 选择一个实例；未指定时采用
NETIZEN_ROOT，再缺省为有效账号的 ~/.netizen。`netizen update` 更新调用它的 Python
环境及其关联实例，拒绝 --root，不是仅更新当前聊天中的机器人。
升级日志逐行显示阶段和每个实例的停止／恢复结果；包验证成功与实例 ready 分开报告。
`netizen update --json` 将最终结构化结果写入 stdout，进度和包管理器输出写入 stderr。

需要查实例清单时，在宿主机执行 `netizen doctor --json`：不传 `--root` 会忽略
NETIZEN_ROOT，列出当前用户全部可识别的受管实例，包含其他 Python 环境和已停止实例。
结果中的 `cli` 表示本次命令的 Python 环境，`count` 是实例数，`instances` 是实例数组；
每项的 `current_environment` 表示是否属于当前 CLI 环境。它不枚举其他用户或手工前台
进程，也不代表升级预检已通过。只查一个实例时用 `netizen doctor --root /path/to/.netizen --json`。

另一个 Python 环境 B 可以按 root 控制绑定 A 的实例，但 start/restart 仍运行 A，
B 的 update 不涉及 A。切换环境必须先 remove 保留数据、解除绑定，再从 B start；
不要加 --purge。remove 默认保留实例数据；--purge 才清理展示的有限实例文件，
-y 只省去交互确认，不能绕过安全检查。实例移除不卸载共享程序，也不删除 Project、
用户 Skills、worktree 内容或共享 Codex 历史；但 purge 清理数据库后受管登记消失，
保留的目录不会自动重新登记或收编。程序卸载交给原包管理器，先处理其关联实例。
