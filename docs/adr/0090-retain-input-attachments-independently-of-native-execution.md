# 输入附件保存原件，生命周期独立于原生执行

用户需要将飞书原文件直接交给 Agent，并自行查看和删除实例保存的原件。采用准备期间
下载、完整发布后提供稳定本地路径的方式；Agent 通过已有工具按需读取，不新增下载 MCP、
全文解析器、模型预处理或附件历史数据库。用户已确认完整发布后即可删除，不等待 Codex
接收确认：接收也不能保证之后的读取不受删除影响，因此不增加受理状态、占用锁或引用图。

## 输入与保留边界

只选择当前消息和既有规则确认的准确逐条引用中的普通文件。独立 `file`、选中 locale/
content 版本中的文件节点及顶层 `post.files` 共用处理；描述符不能替代可见 AST 选择。
catch-up 中其他历史文件、合并转发子项、文件夹和云文档链接不自动下载。图片沿用原路径。
从 typed AST 移除 SDK 生成的文件标签后，正文继续走既有命令、Skill 和 @ 投影；文件名
不会变成命令或 Skill，附件表示只包含不可信元数据、本地路径及“内容尚未读取”的说明。
控制命令（含 Goal objective）不因此接受文件。准入仍在准备前捕获，提交时验证 exact
Binding/Thread/Turn，不因准备耗时而排队或改投。

任一文件下载、本条数量或大小校验、落盘或发布失败，整条输入不提交并由 Netizen 反馈；已有任务
不受影响。原件先进入实例 `attachments/.staging/<batch>`，准备完成后原子发布至
`attachments/retained/<batch>/<safe-name>`。批次记录只有实例归属、准确文件清单、文件
身份、大小和保存时间，不记录原生受理/未知/执行状态，也不存消息正文、回答或原生历史。
发布不是输入受理；原生调用失败、取消和结果未知仍遵循既有 Runtime 语义。

当前操作只清理可证明未交付的本批残留。明确准入拒绝可准确清理该批次，可能已交付、受理后
本地提交失败或原生结果未知则保留。清理失败留下的 staging、半写或未知内容不参与
后续操作判断；不在服务启动时初始化附件目录或扫描清理历史残留。retained 不自动过期，
不随任务结束、归档、会话或 Project 删除联删；现有有限 `remove --purge` 清单也不扩成
递归附件清理。管理员可删除已经或可能交付的文件，提示可能影响当前及后续读取，恢复
方式是重新交付附件，不自动补下载或重放任务。

共享目录仅在使用时按需创建，存在则检查普通目录、服务账号及私有权限后使用。
缺少某个内部目录可直接创建；没有全局归属标记、初始化完成状态或初始化回滚事务。
本批记录绑定固定附件根路径及本批目录/文件身份，不依赖其他批次或全局标记。
目录身份校验限定于当前操作及 Admin 选择凭证，不缓存成跨操作的可用状态。
单次失败、失败后的清理残留均不阻止存储环境恢复后的新操作；未知文件不被递归删除。

首版接受最多 20 个文件，单文件 20 MiB、每条输入合计 50 MiB。只检查当前输入，
不设置实例累计容量配额，不扫描历史附件或其他批次来决定本次能否保存。磁盘不足等
实际写入失败沿用整条输入失败与本次临时文件清理；旧批次的残留或损坏不阻塞新输入。
文件准备批次及实际下载各最多两个；忙时拒绝，没有输入队列。
一次输入顺序下载，只在有界批次内暂存 bytes，落盘后释放。下载单次等待 30 秒、整批
60 秒；等待超时或取消不会提前释放仍在运行的 SDK 下载槽位，迟到结果只释放、不交付。

固定 Channel SDK 完整缓冲后才返回 bytes，没有公开流式接口或可信的下载前文件大小。
上述文件大小是后验接受阈值，**不是传输内存硬上限**；超时也不终止 SDK 阻塞线程。
延续 ADR 0015 的公开下载边界，增加有限附件并发以避免后台请求堆积，不私接 HTTP 或
修改 SDK。公开 SDK 提供有界流式下载后评估迁移；不能把当前限制描述为已解决的能力。

## 管理与权限

Admin 系统管理的“文件附件”使用与 Project 共用的最小浏览控件，固定本实例附件根；
Project 仍只读并保留其 worktree 选择。共用按层读取、文本/Markdown/有限图片预览，
不做全树检索、Office/PDF 解析、任意下载或递归删除。保存时间和短 ID 用于辨认批次，
元数据及删除入口独立于预览支持。仅删除经归属、准确路径、根身份和文件版本核验的单个
原件，复用 Admin 认证、CSRF 和一次性操作授权。最后原件删除后只收掉可证明的内部记录
和空批次，直接在本目录尽力清理，不搬回 staging。文件删除及其持久化确认成功后，
内部记录或空目录清理失败不改变删除成功结果。若记录已移除，即使空目录残留，响应也
表示该批次不再可浏览，前端返回有效目录。出现未知内容则保留。目标文件删除本身
结果未知仍要求刷新，不自动重试删除。

读写使用 descriptor-relative/no-follow 边界，不跟随链接或特殊文件，不把实例根开放给
浏览器或模型；文件访问不绕过原生 sandbox。附件原件不同于 Reply Card 的 exact Turn
输出文件证据。共享浏览组件只抽取已有交互，沿用 ADR 0089 的惰性、安全预览及有界执行器。

## 验证

固定 SDK 归一化样本验证 file/post、@ 准入及准确引用；本地 mock provider 配合真实
bundled App Server 验证 read-only/workspace-write 下新会话、冷恢复及持久分支读取
项目外合成附件，不覆盖用户自定义 deny-read 策略。文件故障、身份替换、取消、本条输入
数量/大小限制、旧批次与新输入独立、人工删除与 UI 竞态由行为测试覆盖。
真实飞书客户端发送入口和 @ 通知、macOS 平台验收
须分别记录，不能由本地合成样本或隔离 Chromium 代替。
