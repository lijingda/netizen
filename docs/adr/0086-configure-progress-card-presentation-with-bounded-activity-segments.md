# 用有界活动分段配置过程卡展示

不同会话需要不同的过程信息容量。沿用聊天默认配置与会话独立配置，在已有任务反馈中
增加过程卡展示设置，只控制已有进展、操作与任务清单的显隐、组织方式、数量和摘要长度。
内容来源、脱敏、时间、状态、原有操作聚合与其他回复模块不变。时间组织以进展分隔操作段，
在段内复用原有聚合，避免另造一套操作日志或聚合语义。

## 配置与捕获

Admin 的会话配置和默认会话配置提供三个内容开关、进展与操作各自的条数/摘要长度，
以及按内容或按时间组织。默认三个内容均开启、按内容组织、进展 4 条/160 字符、操作
8 条/120 字符；正整数上限分别为 8/320、16/240。任务清单原有条数和文字上限不变。
关闭内容保留填写值，三个内容全关仍保留执行状态、失败/中断及观测不可用等必要提示。
已有过程卡总开关及其选择保留；不增加预设、排版、操作类别筛选或预览界面。

默认规则只在原有自动创建入口复制选项，更改默认规则不传播到已有 Binding，也不改变
手动 `/new` 的默认选择。选项随同一份 Task Feedback 在普通 Turn 准入、Goal logical run
开始、Side 创建时捕获；已捕获的执行和已有 Side 不跟随之后的修改。共享消息使用会话
设置，不增加查看者个人配置或动态继承。既有完整配置读写入口必须保留这些选项，不能
因修改模型或其他反馈而重置；定时新话题沿用完整 SessionSettings，原会话目标仍使用
目标 Binding 的配置。

schema v18 通过冻结的 v17 → v18 迁移扩展 Binding 与完整 SessionSettings 的持久形状，
旧值回填上述展示默认值并保留已有反馈选择。启动迁移遵循 ADR 0076，基线仍为 v14；
SQLite 只保存选项，不保存 Activity 正文、事件、分段历史或卡片 session。

## 时间组织与独立保留窗口

按内容沿用最近进展、最近操作、任务清单的现有顺序及整个操作窗口的聚合方式。
按时间按唯一观察链收到事件的顺序，从早到晚交错展示进展与操作段，清单仍在底部；
不按显示时间排序，不补服务端时间。首次进展之前的操作也是一段。

进展与操作分别保留最近 N/M 条，操作先限量再聚合，合并不释放额度或补入更早条目；
单条原生事件自带的 count 保持原有含义。超限逐条淘汰最早条目，不按段整块删除；
进展淘汰不连带淘汰操作，反之亦然。进展关闭或被淘汰只隐藏正文，已有段边界仍有效。

每段使用现有操作聚合规则：子任务按状态聚合，穿插其他操作不打断合并，聚合行位置、
时间与数量继续取原算法；不同段不跨段合并。这有意不承诺段内每条操作严格按时间排列。
同一 item 更新仍覆盖旧状态、移除旧位置并追加到最新位置，进入此次更新对应的段，
不重复展示开始和完成。运行态只给当前有界条目补充顺序与段标记，不保存已淘汰正文。
普通、Side 和 Goal 共用该语义，Goal 换物理 Turn 时仍重置 Activity。

## 投影、分页与容量

安全投影的硬上限与用户选定的展示容量分开；先按既有规则过滤，再限长。操作长度只限制
预览，必要退出码后缀继续保留，极短配置值不截去后缀。工具名、文件/子任务数量、任务清单
上限与原生时间不因展示长度配置改变。继续使用原 observer
或 Goal Tap，不增加消费者、私有 SDK 调用或另一份历史。过程设置不控制阶段性答案、最终
答案、Files、原生问题、表情、结束提及或独立 Goal 管理卡；运行展开、终态折叠不变。

终态文件分页的自包含 manifest 保留当时的展示选择和所需的进展/操作段顺序，翻页与
服务重启后都不读取当前会话设置重建。native item identity 不进入 manifest；旧卡缺少
新增字段时沿用旧组织方式、摘要和时间，不用新默认容量重新裁剪已冻结内容。

通过配置上限约束过程开销，保留现有整卡序列化检查与展示失败路径，不增加按剩余预算
动态缩减过程信息、答案或文件的策略。配置上限不保证整卡可发送：本地满长中文进展、
操作与 12 项清单，加短答案和 9 个短路径文件的自包含分页样本约 69 KB，超过既有
55,000 bytes 检查。保留已确认的 8/320、16/240 上限，超限仍交给原有终态回退，
不把最大配置的合法性等同于整卡容量通过；工具名、答案长度和文件元数据也会影响容量。

本地渲染超限时，阶段性正文与最终正文/Files 沿原有交付路径继续，可能另发完成卡而
不保留过程区；独立文件卡仍超限则回复正文并提示文件卡未生成，原过程卡可能停在最后
成功状态。普通、Side、Goal 共用既有边界；定时新话题已尝试投递后的不重复发布规则不变。

## 验证边界

行为测试覆盖默认兼容、开关与容量、配置迁移/保留/捕获、跨批次分段、隐藏进展、独立淘汰、
操作更新与段内聚合、Goal 重置、旧卡与自包含分页。最大配置组合须核验中文、转义、
callback manifest 的实际编码开销，回归既有超限处理；仓库门禁为 `make check`。
真实 Admin/飞书客户端显示和点击另按部署手册验收，接受本 ADR 不表示已通过容量、
平台或 live 验证，也不授权向未指定的飞书聊天发送测试消息。
