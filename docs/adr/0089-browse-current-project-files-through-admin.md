# Admin 按需查看 Project 当前目录中的文件

服务器部署后的文件查看由现有 Admin 提供，使用相同的实例管理员认证和管理应用边界。
用户已确认首期只读预览，并明确不支持下载。采用本地固定版本 Ace 展示文本、现有
markdown-it-py 渲染 Markdown、浏览器展示有限图片；不引入另一套文件管理服务或在线 IDE。

## 读取身份与权限

默认根是 Project 登记的实际目录，可明确选择同一登记代次的受管 worktree；不会扩张到
仓库根、外部 worktree 或推测某个 Thread 的实际 cwd。停用 Project 仍可查看已有文件；
删除预约、登记代次变化、worktree 未就绪/失去归属或 Git 身份不符则拒绝读取。
根目录身份由登记上下文与文件系统 device/inode 共同确定；客户端后续请求携带该身份，
过期时要求重新选择，不悄悄回退到 Project 目录。

管理员可查看所选根内服务账号有权读取的普通文件，包括未跟踪和隐藏文件；所选根内
名为 `.git` 的目录项不开放。没有新增 Project ACL，也不把 `.gitignore` 当保密规则。服务直接读文件，
不调用模型、不消耗模型 token，也不借用 Codex sandbox 作为 Admin 的读取授权。

路径按目录描述符逐段打开，绝对根祖先和相对路径均拒绝符号链接。即使链接指向根内也
不跟随，以保持可检查的读取边界；目录列表说明链接不可打开。仅接受相对路径，拒绝
越界、特殊文件与不适合表示的路径。读取前后检查目录链及文件元数据，但不承诺并发
写入时的原子快照。此浏览不改变飞书 Files 卡片的 exact Turn 文件证据。

## 有界读取与显示

按层枚举至多 2,000 个目录条目，超限明确显示不完整；不建立后台扫描、索引、文件副本
或数据库内容记录。文件读取与 Markdown 解析使用独立的 2 worker / 4 capacity 有界执行器，
与普通管理阻塞操作分开；取消 HTTP 等待不提前归还仍在执行的 slot。纯读超时明确为
读取超时，不复用写操作的“结果未知/对账”语义。

文本只接受 UTF-8/BOM，最多 1 MiB、10,000 行、单行 20,000 字符。Markdown 排版预览
最多 256 KiB、有限 token/输出与 8 张同根图片；超预算仍可查看符合文本上限的源码。
PNG/JPEG/GIF/WebP 图片最多 5 MiB，头部声明的画布不超过 16M 像素或单边 8192；
不在服务端解码，头部检查不是动画总帧或浏览器解码资源的保证。

代码、文件名和错误按文本显示。Markdown 禁原始 HTML 和危险协议；相对链接通过当前
根重新定位，同根图片走认证接口，远程图片不自动加载。HTML/SVG 按源码处理，不执行。
所有内容 API 与 viewer 资源要求认证；预览响应 no-store/nosniff，图片只返回允许 MIME，
不提供任意文件裸响应、附件端点、下载按钮或下载回退。前端切换根目录、关闭或发现认证失效
时清除内容；这不能收回已被浏览器接收或被用户复制的内容。

## 分发与验证

Ace 的官方浏览器预构建文件固定为 1.45.2，记录原始来源、校验和与 BSD-3-Clause 许可证。
核心与有限语言资源随 wheel/sdist 分发，显式列入认证静态资源路由；文本查看时才
加载 Ace，语言 Worker 关闭。生产环境继续只需要 Python，不增加前端构建或 Node 运行时。

文件服务行为测试、Admin 认证/接口测试、前端状态竞态测试及包资源验证构成代码门禁。
隔离浏览器集成验证与真实飞书 WebView/macOS 验收分别记录，不把窄屏模拟称作真机验证。
