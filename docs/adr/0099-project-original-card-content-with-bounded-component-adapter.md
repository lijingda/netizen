# 从原始卡片统一投影有界正文

消息查询默认返回的接收格式不能证明卡片版本或正文完整性；锁定的 Channel SDK 又会把
部分 1.0 卡片误标成 2.0、漏掉正文，或将 2.0 隐藏交互载荷混入文本。继续叠加摘要识别、
占位符 fallback 和消息副本，不能建立统一的内容来源。采用公开 SDK 取得的原始卡片，
将正文提取收敛成一个可移除的、有界组件适配；1.0 接受尽力交付，并始终说明可能不完整。

适配仅消费公开原始卡片 JSON，包括事件已提供的原始结构或 `user_dsl`，以及公开
`fetch_quoted_context()` 返回的 `user_card_content`。补读必须核验实际返回消息项的目标，
不能把 SDK 用请求值补齐的 ID 当作返回证据。按原始 schema/结构识别版本，不用 SDK
版本标签或接收摘要猜测。提取结果独立于原消息，并成为卡片正文的唯一来源；原消息继续
负责身份、mentions、路由和资源归属。原始卡片 JSON 不整体进入 Prompt。

当前、引用、补充历史和已展开的转发子卡片共用组件提取与语言选择，保留结构和文本预算。
仅解释支持的正文组件，不遍历任意字段作为文字；隐藏交互载荷不进入正文，未知或未读取
内容明确标记。文本字段保留富文本源码，不解析 Markdown/HTML 或证明客户端渲染的
完整性；所有卡片统一说明仅提供文本、未渲染或读取媒体。有限规则描述组件字段及其
可组合的子节点关系，不扩展为客户端渲染器。1.0 可以缺少标题或正文，提取为空时同样
明确提示。卡片文本材料允许携带最小来源 message ID，转发子项可附母消息 ID，供 Agent 按需用
既有飞书工具核对；这是历史 Prompt 精简 ID 规则的窄例外，不新增外层字段、读取权限、
数据库记录或来源索引。
合并转发不逐项补读，既有全包节点、文字、深度和失败边界继续适用。

这项适配依赖公开卡片结构与行为测试，不再保留旧 CardKit quote-text fallback 的精确
SDK 版本分支；ADR 0011 的首层引用关系适配仍保留其精确 1.4.0 门禁。锁定 SDK 升级时
必须重跑实际 SDK 原始读取契约及组件/语言/隐藏内容/各来源一致性测试，真实卡片验收按
[部署门禁](../deployment.md#前置门禁)执行。公开 SDK 出现同等正文文本字段提取能力，并通过这些
测试及真实卡片验收后，切回该 API，删除本地组件适配。

没有采用整包过滤后输出 JSON、复制官方 CLI 转换器或引入 CLI 运行依赖：这些做法会扩大
正文范围或维护面。此决定不更改 Codex Runtime、Scope/Binding、原生执行或持久化边界；
具体提取范围及降级行为以[当前设计](../design.md#引用读取与-sdk-内容适配)为准。
